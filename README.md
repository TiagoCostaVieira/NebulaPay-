# Payment System (Java + Spring Boot)

## 📌 About the Project

This project is a **payment system** being developed using **Java** and **Spring Boot**, focusing on clean architecture, scalability, and real-world backend engineering practices.

The goal is to simulate and implement a modern payment processing service similar to those used in production environments, including payment creation, status tracking, and integrations.

---

## 🚀 Technologies Used

- **Java 17+**
- **Spring Boot**
- **Spring Web**
- **Spring Validation**
- **Maven**
- **REST APIs**
- **Lombok**

---

## 🧠 Project Purpose

This system is being built as a study and engineering project to:

- Understand real-world payment flows
- Practice backend architecture design
- Work with RESTful APIs
- Implement service layers and controllers
- Prepare the foundation for microservices evolution
- Simulate payment provider integrations (e.g., Stripe, gateways)
